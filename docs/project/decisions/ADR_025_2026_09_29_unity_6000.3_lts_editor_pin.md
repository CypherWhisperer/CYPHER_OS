# ADR_025_2026_09_29: Pin the Unity Editor to 6000.3 LTS

**Date:** 2026-09-29
**Status:** Proposed
**Deciders:** CypherWhisperer

<!-- To be promoted to Accepted once the verification checklist in game_development_setup.md confirms 6000.3 runs under the nixpkgs FHS wrapper. -->

---

## Context

- The Game Design and Development course that prompted this setup uses Unity but does not restrict the editor version, so the version is a free choice.

- Unity officially supports only FHS Linux distributions, so `nixpkgs` wraps Unity Hub in an FHS environment (`unityhub`).
- The editors the Hub downloads land in `~/Unity/Hub/Editor/` and are not managed by Nix.
- Nix therefore cannot pin the editor; the version has to be pinned per project.

- Constraints found during research:
    - Unity 6.0 LTS (6000.0) support ends in October 2026, which is imminent.
    - Unity 6.3 LTS (6000.3) is supported until December 2027.
    - On the 6000.6 line, the editor crashes on project open under the `nixpkgs` FHS wrapper because the shader compiler cannot find `libtinfo.so.6` ([NixOS/nixpkgs#561247](https://github.com/NixOS/nixpkgs/issues/561247)).
    - An older report ([NixOS/nixpkgs#346038](https://github.com/NixOS/nixpkgs/issues/346038)) describes Unity 6 failing where 2022.3 worked.

---

## Decision

Projects use **Unity 6000.3 LTS**, pinned per project in `ProjectSettings/ProjectVersion.txt`, installed through the Nix-provided Unity Hub.

---

## Reasoning

- It is the newest line that is both long-supported (through December 2027, beyond the course) and outside the version range with the known NixOS crash. 
- Because the course sets no version, nothing forces a newer mainline release.
- An LTS line also avoids mid-course churn.

- No failure report for 6000.3 under the `nixpkgs` FHS wrapper was found, but no confirmation that it works was found either.
- This ADR stays Proposed until that is tested.

---

## Alternatives Considered

### Unity 6000.0 LTS

Works as a Unity 6 LTS, but support ends in October 2026, so it would be out of support during the course. Rejected on lifespan.

### Latest mainline (6000.6 and above)

Newest features, but the known project-open crash on NixOS (#561247) makes it unusable at present. Rejected until that is fixed.

### Unity 2022.3 LTS

An older report suggests it worked when Unity 6 did not. Its current support status was not checked, and it is a generation behind for a new course project. Kept only as a fallback if 6000.3 fails under the FHS wrapper.

---

## Consequences

**Positive:**

- One stable, supported editor line for the whole course.
- Avoids the known crash.

**Negative / Trade-offs:**

- Pinning is per project and manual: nothing in Nix enforces the version.
- 6000.3 under the FHS wrapper is not yet confirmed working.
- Support ends December 2027, so long-lived projects will need a later migration.

**Neutral / Operational:**

- Revisit if #561247 is fixed in nixpkgs, or when 6000.3 nears end of support.
